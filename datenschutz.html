Datenschutz auf einen Blick
Allgemeine Hinweise
Personenbezogene Daten sind alle Daten, mit denen Sie persönlich identifiziert werden können. Die folgenden Hinweise geben einen einfachen Überblick darüber, was mit Ihren personenbezogenen Daten passiert, wenn Sie diese Website besuchen. Ausführliche Informationen finden Sie in den nachfolgenden Abschnitten dieser Datenschutzerklärung.

Datenerfassung auf dieser Website
Die Datenverarbeitung erfolgt durch den Websitebetreiber. Dessen Kontaktdaten finden Sie im Abschnitt „Verantwortlicher“. Ihre Daten werden zum einen dadurch erhoben, dass Sie uns diese mitteilen (z. B. per E-Mail). Andere Daten werden automatisch beim Besuch der Website durch unsere IT-Systeme erfasst (z. B. Browser, Betriebssystem, Uhrzeit des Seitenaufrufs, IP-Adresse).

Wofür nutzen wir Ihre Daten?
Ein Teil der Daten wird erhoben, um eine fehlerfreie Bereitstellung der Website zu gewährleisten. Daten, die Sie uns mitteilen, verwenden wir ausschließlich zur Bearbeitung Ihrer Anfrage. Wir setzen keine Analyse- oder Tracking-Dienste ein.

Welche Rechte haben Sie?
Sie haben jederzeit das Recht auf Auskunft, Berichtigung oder Löschung Ihrer Daten. Weitere Rechte sind im Abschnitt „Ihre Rechte“ beschrieben.

Hosting über GitHub Pages
Diese Website wird über GitHub Pages bereitgestellt. GitHub verarbeitet beim Besuch Server-Logdaten wie IP-Adresse, Browsertyp/-version, Betriebssystem, Referrer-URL sowie Datum und Uhrzeit des Zugriffs. Dies dient der technischen Bereitstellung und Sicherheit der Website (Art. 6 Abs. 1 lit. f DSGVO). Wir haben keinen Zugriff auf diese Logdateien. Weitere Informationen finden Sie in der GitHub Privacy Statement.

Datenübermittlung in Drittländer
GitHub hat seinen Sitz in den USA. Dadurch kann eine Verarbeitung personenbezogener Daten in einem Drittland erfolgen. GitHub nutzt hierfür geeignete vertragliche Schutzmaßnahmen (u. a. EU-Standardvertragsklauseln).

Community-Live-Daten (evcc)
Auf der Startseite wird ein Live-Widget mit aggregierten Community-Werten angezeigt. Dafür stellt Ihr Browser eine Verbindung zu api.evcc.io her. Dabei können technische Daten (z. B. IP-Adresse, Zeitpunkt, User-Agent) an evcc übermittelt werden. Angezeigt werden ausschließlich anonymisierte, aggregierte Werte.

KI-gestützte Kompatibilitätshilfe „Frag mich“
Wenn Sie die Kompatibilitätshilfe verwenden, verarbeiten wir Ihre eingegebene Frage, eine zufällig im Browser erzeugte Kennung in gehashter Form sowie die erzeugte Antwort und deren Quellen. Die Verarbeitung erfolgt über einen Cloudflare Worker und Cloudflare D1. Zur Beantwortung wird die Frage an die OpenAI API übermittelt; OpenAI verarbeitet die Eingabe zur Erzeugung der Antwort. Die API-Anfrage wird von uns mit deaktivierter Antwortspeicherung ausgeführt. Bitte geben Sie keine Namen, Kontaktdaten oder anderen personenbezogenen Informationen in das Fragenfeld ein. Die Daten dienen der Beantwortung, Missbrauchsbegrenzung und Verbesserung unserer Dokumentation. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO. Unser berechtigtes Interesse liegt in einer hilfreichen, sicheren und wirtschaftlich betreibbaren Produktinformation. Sie können die Löschung einer Frage unter Angabe von Inhalt und ungefährem Zeitpunkt per E-Mail an ehive@gmx.de verlangen.

Kundenberichte mit Fotos
Wenn Sie einen Kundenbericht einreichen, verarbeiten wir Ihren Anzeigenamen, Ihre E-Mail-Adresse, Angaben zu den eingesetzten Komponenten, den Bericht, Bildkommentare und die hochgeladenen Fotos, um den Beitrag zu veröffentlichen und bei Rückfragen Kontakt aufzunehmen. Die Übermittlung wird durch einen Cloudflare Worker verarbeitet. Textangaben und Bildmetadaten werden in Cloudflare D1, die Fotos in Cloudflare R2 gespeichert. Zum Schutz vor automatisierten Einsendungen verwenden wir Cloudflare Turnstile. Ihre E-Mail-Adresse wird nicht veröffentlicht. Anzeigename, Bericht, Komponenten, Bildkommentare und Fotos erscheinen unmittelbar nach dem Absenden öffentlich auf der Website. Bitte entfernen Sie vor dem Hochladen unerwünschte Aufnahme- und Standortmetadaten aus Ihren Bildern. Zur späteren Bearbeitung oder Löschung wird ein geheimer Bearbeitungsschlüssel im lokalen Speicher Ihres Browsers abgelegt; auf dem Server wird nur dessen nicht rückrechenbarer Hash gespeichert. Andere Besucher können problematische Beiträge melden; dabei speichern wir Meldegrund, Zeitpunkt und eine gehashte Browserkennung. Sie können uns unter ehive@gmx.de kontaktieren, um die Veröffentlichung zurückzuziehen oder die Löschung Ihrer Einreichung zu verlangen.

Unsere Website kann externe Inhalte (z. B. Logos, SVGs oder Links) einbinden. Beim Abruf solcher Inhalte wird eine Verbindung zu den Servern der jeweiligen Anbieter hergestellt. Für deren Datenschutzpraktiken gelten die Informationen der Anbieter.

Datensparsame Reichweitenmessung
Wir setzen keine Analyse-Cookies und keine werblichen Tracking-Dienste ein. Zur Verbesserung der Website zählen wir ausgewählte Aktionen wie geöffnete Shop- oder Dokumentationslinks, Datenblatt-Downloads, gestartete KI-Fragen und gesendete Kundenberichte. Dafür werden Ereignisname, Seitenpfad, Zeitpunkt und eine gehashte, zufällig im Browser erzeugte Kennung gespeichert. Die Auswertung dient ausschließlich aggregierten Statistiken; ein geräteübergreifendes Profil wird nicht erstellt. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO.

Speicherdauer
Personenbezogene Daten speichern wir nur so lange, wie dies für die jeweiligen Zwecke erforderlich ist. E-Mail-Anfragen werden nach abschließender Bearbeitung gelöscht, sofern keine gesetzlichen Aufbewahrungspflichten bestehen. KI-Fragen samt Antworten und Quellen, Messereignisse sowie Meldungen zu Community-Beiträgen werden gespeichert, solange sie für die Verbesserung, Sicherheit und Auswertung der angebotenen Funktionen benötigt werden oder gesetzliche Pflichten bestehen. Veröffentlichte Kundenberichte und Fotos bleiben bis zur Löschung durch den Verfasser, durch uns oder bis zum Wegfall des Veröffentlichungszwecks gespeichert. Betroffene Personen können die Löschung ihrer personenbezogenen Daten verlangen, soweit keine gesetzlichen Gründe entgegenstehen.
